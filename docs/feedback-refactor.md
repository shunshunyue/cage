# 反馈改进实施记录

日期：2026-11-03。对应《Cage 框架技术与开发体验反馈》的 F01–F13、DX01–DX07。内容为当前工作区源码改进，尚未发布 npm。

本轮允许调整 API，无线上兼容包袱；按单机、API 与 worker 同版本升级设计。敏感明文可靠审计失败时拒绝交付。批量边界根据现有租赁业务及回归确定：配发整单原子、归还每次提交的一批原子、本地结算原子、外部财务异步恢复。

## 技术条目

| 编号 | 实施结果 | 主要证据与边界 |
| --- | --- | --- |
| F01 | 同进程运行标记与跨实例 advisory lock；统一跟踪在途任务，有界停机、取消外部 IO | 跨周期、两实例争抢、运行中停机、停机超时回归；超时不提前释放仍在使用的锁 |
| F02 | 保留可表达的 strict / multipleOf / default 等校验；不可表达规则按字段报告 CAGE-GEN-003，OpenAPI 标识服务端校验 | 比较接受结果与解析输出；转换、regex flags、递归续层等显式降级，服务端最终校验 |
| F03 | fetch 及响应体错误统一封装；signal / timeout；mutation 失败抛 CageCommandError、成功返回 data | 断网、响应体故障、401、CSRF、取消、超时与领域拒绝回归；取消等待不保证服务端未提交 |
| F04 | 每客户端独立会话；退出/401/切换账号清理身份、能力、在途请求与旧响应；范例取消并清除查询缓存 | 多实例隔离、晚到身份响应及退出回归 |
| F05 | HTTP、独立 worker、默认内核日志均优先元数据白名单；声明驱动递归脱敏；隐藏错误原文与 URL 参数 | 多层对象、数组、循环引用、合成隐私标记回归；自定义日志仍由应用负责 |
| F06 | trustProxy 默认 false，可显式配置可信地址/网段；限流与来源使用相同解析结果 | 直接访问与明确可信代理的伪造头回归；限流预算是单进程 |
| F07 | 监听异常禁用缓存；重连清空；代次检查阻止旧请求回填 | 断线、撤权、重连、旧 resolve 回填的真实数据库故障注入 |
| F08 | 连接器外呼移出事务，租约领取并可靠保存回执，短事务回写；连接、事务、网络均有界 | poolSize=1、回写失败复用回执、未知结果停止盲目重试；导出指纹和审计复用持有事务，无第二连接等待 |
| F09 | 必要引擎缺失拒绝启动；事件/消费者清单校验；运行版本、指纹和心跳 | 缺消费者、未知事件不会静默 done；纯记录事件允许归档；首阶段要求同版本部署 |
| F10 | 可靠敏感读取、自定义 query 用途审计、导出生成/下载审计；登录失败审计故障可观测 | 各入口注入审计故障；完整保证与尽力记录差异见[审计矩阵](ai/architecture.md#审计保证) |
| F11 | 生产 Cookie 密钥校验；显式 bootstrap 及新受限凭据文件；提交前交付凭据，失败整体回滚；healthz/readyz 分离 | 不隐式初始化、不向服务日志输出初始密码；readyz 检查数据库及授权监听，worker 另有心跳 |
| F12 | 异步 scrypt；认证并发和等待队列有界；输入长度提前拒绝 | 队列、异常释放及可控非阻塞回归；没有据此报告生产吞吐或 P95 |
| F13 | 页码/偏移安全整数，有限数值、严格布尔、合法 ISO 日期，字段级错误；UUID SQL 前校验与排序白名单 | 非法与合法参数真实数据库回归；保留 pageSize 上限规范化，当前仍为 offset + 精确计数 |

## 迁移与部署

新增系统迁移 `cage:0003_runtime_reliability`，保存连接器执行/租约/回执及 worker 心跳，并为同步记录增加租户隔离键。已发布的历史系统迁移和业务迁移没有改写。部署前审查迁移，再显式 migrate；本轮没有执行业务数据库迁移。

运行指纹用于核对当前声明结构和函数文本，不能证明任意闭包依赖或 JavaScript 行为等价。doctor 使用实际 dist 入口，并按源码对应产物检查新鲜度；非标准构建或缺证据标为 unknown。真实外部幂等协议、人工核对与补偿仍需按第三方系统验收。

不可重试外部写入进入 unknown 后，当前没有通用的回执确认或解除未知状态入口，普通死信重放不会解除。需按具体连接器制定受控恢复或业务补偿，不能把“阻止盲目重试”写成已具备通用人工恢复平台。
