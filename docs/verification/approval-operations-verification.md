# 框架流程时效验收（2026-11-07）

本批能力属于 Cage 框架，实现在 `packages/approval`、`packages/client`、`packages/http`、`packages/admin` 及 CLI 能力发现/图谱。没有修改采购领域字段、命令或业务页面。采购仅在独立演示启动脚本中接入公共声明，用于真实业务验证。

## 已交付

- `approvalOperations()` 独立运行时，复用既有 worker 和宿主数据库连接池。
- 人工节点 `sla` 自然分钟总时限、临期与超时站内提醒；领取、转办、委派和加签不重置。
- `route.reminders` 指定申请人字段和持久冷却，`urgeApproval` 绑定实例/节点，接收人由服务端当前任务计算。
- 本人提醒读取、游标分页、幂等已读、通用 Admin 我的申请/流程提醒/待办截止时间。
- 当前权限与接收关系校验、多 worker 去重、停机补发当前阶段、通知/历史/冷却共同提交。
- 前向系统迁移 `cage:approval_deadlines_003`；旧轮次没有政策或截止，不自动启用。

接入与完整边界见 [审批流转与流程时效](../development/guides/approvals.md)。工作日历、自动升级、外部邮件/短信、指定节点退回、流程分支和可视化设计器不在本批范围。
