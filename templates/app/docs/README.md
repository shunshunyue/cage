# 本地框架文档

编程 agent 先读项目 [AGENTS.md](../AGENTS.md)，按 [Cage 开发 Skill](development/skills/cage-development/SKILL.md) 理解需求、澄清、查证能力、说明实现映射，再编码与验收。

[任务导航](development/README.md) 说明各类文档的分工，按本次需要选择资料：

- `development/getting-started`：运行模型、完整业务链和操作命令。
- `development/guides`：[业务澄清](development/guides/business-collaboration.md)、[能力选择与实现映射](development/guides/recipes.md)、各专题接入。
- `development/reference`：原语与工程规范。
- `development/tools`：诊断、本体查询和排错。
- `development/examples`：教学源码与采购导读。
- `development/skills`：唯一的 agent 工作流程。
- [错误码册](errors/README.md)：按实际错误定位原因。
