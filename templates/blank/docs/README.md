# 本地框架文档

[开发手册](development/README.md)是人与 AI 共用的当前教材。

- 初次使用：[启动](development/getting-started/start.md) → [执行模型](development/getting-started/architecture.md) → [第一个业务](development/getting-started/first-feature.md)。
- 直接开发：从手册选择审批、关系、文件、自动化或 AI 等任务。
- 查 API 和规则：进入 development/reference；故障查[排错](development/tools/troubleshooting.md)与[错误码](errors/README.md)。
- 编程 AI：先读项目 [AGENTS.md](../AGENTS.md)和[开发 Skill](development/skills/cage-development/SKILL.md)，按任务加载。

本地教材随框架分发，采购参考源码不代表应用已启用该业务。客户规则保留在项目文档或 AGENTS 托管区外。
