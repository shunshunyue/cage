# @yss123/cage-testkit

派生测试运行器、fake 仓储、测试数据库

Cage 是通过 TypeScript 声明业务、由框架统一执行权限和数据规则的中后台框架。此包是框架的一部分。

## 使用

```powershell
pnpm add -D @yss123/cage-testkit
```

首次使用建议通过脚手架创建完整项目，所需依赖由模板统一配置。需要 Node.js 24 或更新版本。
